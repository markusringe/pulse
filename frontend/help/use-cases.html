Typische Szenarien (Use-Cases)

Drei durchgängige Beispiele — jeweils mit Ziel, Zeit und häufigen Fehlern.

Use-Case 1: Bürgerversammlung (~200 Teilnehmende, ~90 Min.)

Ziel

Öffentliche Beteiligung mit Umfragen, Wortwolke und moderiertem Q&A.

Vorbereitung (~30 Min.)

  1. Event „Bürgerversammlung Klimaschutz 2026“ anlegen, Status später aktiv.
  2. Deck: 3× MC, 2× Wortwolke, 2× Q&A, 1× Quiz — unter #/admin/sessions/<code>.
  3. Einstellungen: Wortfilter an, Fragen-Intervall 30 s, Lobby aktiv.
  4. Beamer-Test, zweites Handy als Teilnehmer.

Durchführung

Lobby → Umfragen mit Reveal → Wortwolken → Q&A moderieren → Quiz-Abschluss → Q&A-Export.

QR groß auf Leinwand; Code zusätzlich vorlesen. Bei 200+ Teilnehmenden: stabiles WLAN, ggf. Docker mit Redis.

Fehler vermeiden: Event noch geplant — Teilnehmende sehen Wartehinweis, können aber noch nicht abstimmen. Status vor Start auf aktiv setzen oder Startzeit abwarten.

Use-Case 2: Team-Meeting mit Quiz (~30 Min.)

Ziel

Lockere Check-in-Umfrage und Wissens-Quiz im Team.

Vorbereitung (~10 Min.)

  1. Ad-hoc-Session unter Sessions (kein Event nötig).
  2. Deck: 1× MC Check-in, 3× Quiz, 1× Bewertungsskala Feedback.
  3. Quiz: Teams erlauben, Power-Ups an.

Durchführung

Kurzer Join-Code im Chat → Quiz erklären → Rangliste zeigen → Skala für Retro.

Keine Lobby nötig — Demo- und Quiz-Vorlagen überspringen den Warteraum.
Use-Case 3: Schulung mit Skalen (~15 Min. Selbstlernen)

Ziel

Wissens-Check und Feedback nach Schulungsmodul.

Vorbereitung (~15 Min.)

  1. Wiederkehrendes Event anlegen (gleicher Code pro Termin).
  2. Deck: 5× MC, 3× Bewertungsskala.
  3. Ergebnisse sofort zeigen (R dauerhaft an oder nach jeder Folie).

Durchführung

Teilnehmende arbeiten selbstständig durch — Presenter nur bei Bedarf eingreifen.

Hinweis: Hybride Tools (Webex, Teams): Join-Link von Pulse separat teilen — keine native Integration.

Use-Case 4: Ortsauswahl mit Picker (~50 Städte)

Ziel

Teilnehmende wählen ihren Wohnort aus einer langen Liste — ohne 50 Buttons auf einmal.

Vorbereitung (~20 Min.)

  1. Folientyp Picker, 50 Städte per Massen-Import (eine Zeile pro Stadt).
  2. Kategorien nach Bundesland, List-Layout, Suche aktiv.
  3. Single-Select, Ergebnisse erst nach Reveal.
