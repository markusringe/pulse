Anmelden mit E-Mail-PIN

Die Administration nutzt ein passwortloses Login: Sie geben Ihre E-Mail-Adresse ein, erhalten einen sechsstelligen Code per E-Mail und melden sich damit an. Das Kennwort dient nur beim Anlegen des Kontos oder bei Kennwortänderungen — nicht für die tägliche Anmeldung.

Ablauf

  1. #/admin/login öffnen
  2. E-Mail eingeben → „Code senden“
  3. Code aus der E-Mail eingeben (10 Minuten gültig, einmal verwendbar)
  4. Optional „Angemeldet bleiben“ (30 Tage) oder „Nicht angemeldet bleiben“ auf gemeinsamen Rechnern

Rollen

Administrator
Vollzugriff inkl. Benutzerverwaltung, Branding, SSL, Einstellungen
Editor
Events und Sessions anlegen und bearbeiten — keine globalen Einstellungen
Viewer
Nur freigegebene Events ansehen oder präsentieren

PIN kommt nicht an?

  • Spam-/Junk-Ordner prüfen
  • Kurz warten, dann „Neuen Code senden“ (nach 30 Sekunden)
  • Administrator: SMTP-Konfiguration und /api/health prüfen
  • Lokal: Entwicklungs-Mailbox unter Login sichtbar, wenn AUTH_DEV_MAILBOX=1

Session-Presenter mit Join-Code bleibt unverändert — Teilnehmende brauchen kein Konto. Events: Presenter melden sich mit Rolle an.
