Begriffe im Überblick

Event vs. Session
Event = öffentliche Hülle auf der Startseite. Session = technische Umfrage mit Folien und Ergebnissen. Ein Code für beides.
Deck vs. Folie
Deck = gesamte Abfolge. Folie = ein Interaktionsschritt (Typ + Frage + Optionen).
Join-Code vs. Admin-Schlüssel
Join-Code für Teilnehmende. Admin-Schlüssel (Browser nach Start) oder Anmeldung mit Presenter-Rolle für Steuerung.
Lobby vs. Reveal
Lobby = Warteraum vor dem ersten Slide. Reveal = „Ergebnisse zeigen“ (R) für Umfragen/Wolke.
Ad-hoc ohne Event: Unter Sessions starten — kein Katalogeintrag auf der Startseite, Join nur per Code/QR.
