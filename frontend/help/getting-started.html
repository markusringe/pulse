Schnellstart in 5 Minuten

Zuerst lesen: Session-Architektur verstehen (2 Min.) — dann ist klar, was Event, Session und Deck bedeuten.
Transkript (Textversion des Videos)
  1. 0:00 — Administration öffnen, Sessions-Formular.
  2. 0:45 — Erste Folie: Multiple Choice, Frage + Optionen.
  3. 1:30 — Wortwolke und Q&A zur Liste hinzufügen.
  4. 2:15 — „Session starten“, Join-Code notieren.
  5. 3:00 — Zweites Gerät: Code eingeben, Lobby.
  6. 4:00 — „Los geht's“, abstimmen, R für Ergebnisse.
  7. 5:00 — Nächste Folie, Export-Hinweis.
  1. Session oder Event anlegen. Ad-hoc: Administration → Sessions (#/admin) — Formular in vier Blöcken (Grundlagen, Optionen, Typ-Einstellungen, Erweitert). Geplant: Events anlegen — danach Deck unter #/admin/sessions/<code>. Für lange Listen (10–50 Optionen): Folientyp Picker. Teilnehmende: veröffentlichte Event-Karten oder Code #/join/123456.
  2. Code teilen. Auf der Leinwand steht ein sechsstelliger Join-Code plus QR-Code. Teilnehmende öffnen Pulse und geben den Code ein — oder scannen den QR. Am Handy liegen Abstimmung und Reaktionen unten in der Daumenzone.
  3. Optional: Lobby. Neue Sessions starten im Warteraum (großer QR, Teilnehmerzahl). „Los geht’s“ blendet die erste Folie ein. Demo- und Quiz-Vorlagen überspringen die Lobby.
  4. Abstimmen lassen. Balken, Wortwolke oder Fragenliste aktualisieren sich live. „Ergebnisse zeigen“ blendet Auswertungen ein oder aus (Taste R). Vorher sehen Teilnehmende nur, dass die Stimme ankam.
  5. Weiterblättern. Nächste Folie mit „Weiter“, Pfeil rechts oder Leertaste (nicht während eines Quiz-Timers). Bis zu 40 Folien im Deck; live hinzufügen, Inhalt bearbeiten, duplizieren oder löschen (Deck-Editor oder Presenter).

Beim ersten Besuch erscheint eine kurze Tour. Sie können sie überspringen oder später nachholen — sie schließt sich nicht von selbst nach wenigen Sekunden.
