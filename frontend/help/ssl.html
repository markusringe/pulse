SSL-Zertifikate

Pulse kann kostenlose Zertifikate von Let’s Encrypt beantragen. Die Domain muss per DNS auf diesen Server zeigen, Port 80 muss erreichbar sein (HTTP-01-Challenge). Hinter einem Reverse-Proxy den Pfad /.well-known/acme-challenge/ unverändert an die App weiterleiten. Es gibt keine Wildcards, keine IP-Zertifikate und kein localhost.

Status-Badges

  • Aktiv — Zertifikat gültig, HTTPS kann lauschen.
  • Läuft — Antrag ist unterwegs, die Seite aktualisiert sich von selbst.
  • Fehler — Domain, E-Mail oder Challenge prüfen; Meldung unter dem Badge lesen.
  • Abgelaufen — erneuern oder neu beantragen. Optional „automatisch erneuern“ (Prüfung stündlich, Fenster etwa 30 Tage vor Ablauf; Zertifikate gelten 90 Tage).

Staging-Umgebung ist nur für Tests: Browser vertrauen diesen Zertifikaten nicht. Private Schlüssel liegen auf der Platte (nicht in der normalen SSL-API). Im Settings-Export Schema 2 sind die PEM-Dateien enthalten — die Sicherungsdatei wie ein Secret behandeln.
