Admin: Branding, Schlüssel, Checkliste

Die Administration hat eine durchgehende Menüleiste: Sessions, Events, Branding, Datenschutz, SSL, Einstellungen, Hilfe.

Sessions und Events

  • Sessions (#/admin) — ad-hoc-Session anlegen: Formular in Blöcken (Grundlagen, Folien-Einstellungen, Typ-Optionen, Folienliste, Zugang, Vorlagen), Sidebar „Letzte Sessions“
  • Events — Veranstaltungen mit festem Join-Code für die Startseite (Titel, Datum, Status)
  • #/admin/sessions/<code> — Deck-Editor: Folieninhalt bearbeiten (Inline/Modal), Bulk, kopieren, sortieren

Ein Event ist genau eine Session (ein Code, ein Deck). Folien liegen nicht im Event-Datensatz. Ausführlich: Events und Session-Decks.

Installation (Server)

  • Lokal: ./scripts/install.sh oder npm run setup
  • Docker: ./scripts/install.sh --docker
  • VPS Ubuntu: sudo ./scripts/install-vps-ubuntu.sh oder npm run setup:vps — installiert Docker, seedet data/, startet Compose

Grundeinstellungen (Branding, Datenschutz) legt scripts/seed-data.sh an. Geheimnisse nach VPS-Setup in INSTALL-CREDENTIALS.txt. Ausführlich: Installation und Betrieb, docs/installation.md.

Admin-Schlüssel

Beim Start einer Session bleibt der Schlüssel in diesem Browser (sessionStorage). Ohne ihn sind Folienwechsel und Moderation geschützt. Ein anderes Gerät braucht das optionale Presenter-Passwort oder denselben Schlüssel.

Branding

Unter Branding nur das Erscheinungsbild: Logo, Farben, White-Label (App-Name, Favicon, Domain-Hinweis, Footer ausblenden), Schrift, Folienhintergrund, Übergang, optionaler Sound (Standard stumm), Sprachen und Homepage-URL. Standardfarben der Stadt-CI: Stadtblau #007CC1 und Orange #F99700 — Orange nicht als Text auf Weiß; die App übernimmt Markenfarben nur bei ausreichendem Kontrast. Interne Dateinamen und Speicher-Prefix ändern sich durch den App-Namen nicht.

Datenschutz

Unter Datenschutz Rechtstexte (Verantwortliche Stelle, DSB, Aufsicht), öffentliche Links, Aufbewahrungsfrist und Ergänzungen zur Datenschutzerklärung. Die öffentliche Ansicht bleibt Datenschutz und Impressum.

Einstellungen und Sicherung (Schema 2)

Unter Einstellungen: Frage-Intervall, Q&A-Zeitlimit, Wortfilter und die Datei pulse-settings.json. Enthalten sind Branding inkl. Logo, Rechtstexte mit Versionshistorie sowie SSL-Metadaten und PEM-Dateien (private Schlüssel). Schema 1 ohne PEM bleibt importierbar. Nicht enthalten: Sessions, Umfrageantworten, Audit-Logs und das Admin-Secret. Die Datei wie ein Passwort aufbewahren. Import lädt HTTPS neu, ohne den Prozess zu beenden.
