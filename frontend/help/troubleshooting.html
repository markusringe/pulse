│       │

│           │
│           └─ Server erreichbar? ── Nein ──► IT / Healthcheck prüfen
│               │
│               └─ HTTPS ok? ── Nein ──► Siehe „HTTPS funktioniert nicht“
│                   │

│                       │

HTTPS funktioniert nicht

Start: Browser warnt vor Zertifikat / keine HTTPS-Verbindung
│
├─ DNS zeigt auf Server? ── Nein ──► A/AAAA-Eintrag korrigieren
│   │
│   └─ Port 80 erreichbar? ── Nein ──► Firewall (UFW) / nginx prüfen
│       │
│       └─ Zertifikat in Admin aktiv? ── Nein ──► #/admin/ssl — Domain beantragen
│           │
│           └─ ACME-Challenge durchgereicht? ── Nein ──► nginx: /.well-known/acme-challenge/
│               │
│               └─ Staging-Zertifikat? ── Ja ──► Produktions-Zertifikat ohne Staging
│                   │
│                   └─► Browser-Cache leeren, erneut testen

Details: SSL-Zertifikate.

Die Anzeige bleibt bei „Verbinde …“

Pulse baut die Live-Leitung (WebSocket) automatisch wieder auf. Offline-Banner bis „Live“. WLAN prüfen, Seite neu laden. Lokal ohne Server: „Demo“. Mehrere Server-Instanzen: REDIS_URL setzen.

Präsentation gesperrt / Zugriff verweigert

Admin-Schlüssel (Start-Browser) oder Presenter-Passwort. Nach drei Fehlversuchen: 5 Minuten Sperre.
