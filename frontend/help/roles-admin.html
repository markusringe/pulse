Guide: Instanz-Admin

Dauer: ca. 30 Minuten · Zugang: ADMIN_SECRET in .env (Header X-Admin-Key)

1. Einrichtung

  1. Installation (lokal, Docker oder VPS).
  2. Branding: Logo, Farben, App-Name, Sprachen.
  3. Datenschutz & Impressum pflegen.
  4. SSL (Let’s Encrypt) nach DNS & Port 80.
  5. Einstellungen: Export pulse-settings.json (Schema 2) sichern.

2. Betrieb

  • Events: Status aktiv für öffentlichen Join.
  • Deck-Editor: #/admin/sessions/<code> — Folieninhalt bearbeiten, Bulk, kopieren.
  • Daten-Backup: Verzeichnis data/ (pulse.db, JSON, ssl/).
  • Updates: git pull, docker compose up -d --build.

3. Debug-Checkliste

SSL#/admin/ssl
Secrets.env / INSTALL-CREDENTIALS.txt (VPS)
pulse-settings.json enthält private SSL-Schlüssel — wie ein Passwort behandeln. Keine Sessions/Events im Export.
