Pulse

Teilnehmer-Guide

Handy oder Laptop. Kein Konto. Zum PDF: Drucken → Als PDF sichern.

Zur Hilfe

Beitreten

  1. Adresse der Veranstaltung öffnen, QR auf der Startseite/Event-Karte scannen oder sechs Ziffern von der Leinwand eingeben (#/join/…).
  2. Beim Quiz optional einen Teamnamen. Bei geplanten Events warten, bis der Status aktiv ist.
  3. Bei „Gleich geht’s los“ warten — der Präsentator startet die Lobby.

Mitmachen

  • Umfrage / Bildwahl / Skala: eine Antwort antippen. Sie sehen eine Bestätigung, nicht unbedingt schon das Ergebnis.
  • Picker (lange Listen, 10–50 Optionen): Suche nutzen, ggf. Kategorie wählen, eine oder mehrere Optionen markieren und bestätigen.
  • Ranking / 100 Punkte / Termin: Reihenfolge setzen, genau 100 Punkte verteilen oder Zeitfenster wählen (mehrere Slots möglich).
  • Freitext / Wortwolke: kurzen Satz bzw. ein Wort senden.
  • Q&A: Frage schreiben, Kategorie wählen, optional privat. Interessante Fragen per Upvote nach oben holen.
  • Quiz: schnell die richtige Option(en) wählen, solange der Timer läuft. 50:50 und Doppelpunkte je einmal.
  • Reaktionen: Emojis unten in der Daumenzone — sie schweben kurz auf der Leinwand, werden nicht gespeichert.

Auf dem Handy: waagerecht wischen wechselt nur zwischen den Karten auf Ihrem Gerät, nicht die Folie auf der Bühne. Nach dem Senden kann das Gerät kurz vibrieren.

Probleme

„Session gibt es nicht“: Code erneut von der Leinwand. Offline-Banner: WLAN, Seite neu laden. Blockierte Frage: andere Formulierung, Wortfilter kann greifen. Probe-Hinweis: der Präsentator übt — es wird kein Live-Publikum erwartet.
