Häufige Fragen

Brauchen Teilnehmende ein Konto?

Nein. Code eingeben oder QR scannen reicht. Optional ein Teamname beim Quiz.

Funktioniert es ohne Internet?

Der Live-Modus braucht den Server. Ohne Backend schaltet die App auf einen Demo-Kanal (zwei Tabs im selben Browser können sich sehen). Bei Verbindungsabbruch erscheint ein Offline-Banner; die App baut die Leitung selbst wieder auf.

Kann ich Ergebnisse erst später zeigen?

Ja. „Ergebnisse zeigen“ bzw. Taste R. Vorher sehen Sie nur, dass Stimmen da sind. Q&A und Quiz sind davon ausgenommen.

Wie viele Folien?

Mehrere Folien als Liste vorbereiten oder live hinzufügen. Höchstens 40 Folien. Typen: Multiple Choice, Wortwolke, Q&A, Quiz, Bewertungsskala, Ranking, 100 Punkte, Freitext, Bildwahl, Terminfindung, Picker (10–50 Optionen).

Was ist der Proben-Modus?

Checkbox oder Button „Probe“ auf der Startseite. Banner ohne Live-Publikum; der Join-Link lässt sich in der UI nicht kopieren. Beitritt per bekanntem Code bleibt technisch möglich.

Geht das auf dem Handy?

Ja. Abstimmung und Reaktionen liegen unten in der Daumenzone. Wischen wechselt nur lokale Karten, nicht die Folie auf der Bühne.

Kann eine Q&A-Frage privat sein?

Ja. Andere Teilnehmende sehen sie nicht; Autor und Präsentator schon. Kategorien helfen beim Filtern.

Was ist der Unterschied zwischen Session und Event?

Eine Session ist die laufende Umfrage mit Code, Folien und Ergebnissen. Ein Event ist die öffentliche Hülle (Titel, Datum, Status) mit demselben sechsstelligen Code. Es gibt nur ein Deck pro Event — keine getrennten „Sets“. Ad-hoc-Sessions ohne Event-Karte legen Sie unter #/admin an.

Warum kann ich einem Event nicht beitreten?

Bei Status geplant oder archiviert ist der Join für Teilnehmende gesperrt. Nur aktive Events erlauben den Beitritt über die Startseite. Beendete Events zeigen Ergebnisse, aber keinen neuen Live-Join für Unbekannte.

Wo bearbeite ich die Folien eines Events?

Unter #/admin/sessions/<code> (Link aus der Event-Liste oder nach dem Anlegen). Dort Folieninhalte ändern (Stift oder Doppelklick), sortieren, aus einer anderen Session kopieren und löschen. Einfache Typen öffnen einen Inline-Editor, komplexe ein Modal — siehe Events und Session-Decks.

Was ist der Unterschied zwischen Picker und Multiple Choice?

Multiple Choice hat 2–6 Optionen auf einen Blick. Picker ist für lange Listen (10–50): mit Suche, optionalen Kategorien und Darstellung als Liste, Raster oder Dropdown. Details: Picker-Hilfe.

Kann ich mehrere Folien auf einmal ändern?

Ja. Im Deck-Editor Folien per Checkbox auswählen (Shift = Bereich). Die Bulk-Leiste bietet Eigenschaften (Ergebnisse verbergen/zeigen, geplante Minuten, Notizen), Duplizieren und Löschen.

Gibt es ein Video?

Noch nicht. Artikel mit „Video folgt“ sind Transkripte; es werden keine Filmdateien mitgeliefert.

Wie installiere ich Pulse auf einem Server?

VPS Ubuntu: sudo ./scripts/install-vps-ubuntu.sh (Docker inklusive). Docker lokal: ./scripts/install.sh --docker. Ohne Docker: ./scripts/install.sh und npm start. Ausführlich: Installation und Betrieb.
